Go предоставляет набор функций для работы со строками в пакете `strings`. Эти функции не требуют создания новых типов и работают напрямую со значениями типа `string`.

Чтобы использовать их, нужно импортировать пакет:

```go
import "strings"
```

## Приведение к нижнему и верхнему регистру

```go
strings.ToLower("HeLLo") // "hello"
strings.ToUpper("HeLLo") // "HELLO"
```

## Проверка начала и конца строки

```go
strings.HasPrefix("golang", "go")       // true
strings.HasSuffix("version.go", ".go")  // true
```

## Поиск подстроки

```go
strings.Contains("hello world", "world") // true
strings.Index("hello world", "lo")       // 3
strings.Index("hello world", "go")       // -1
strings.LastIndex("archive.tar.gz", ".") // 11
```

`strings.LastIndex()` ищет подстроку с конца строки и возвращает позицию последнего вхождения. Если подстроки нет, она, как и `strings.Index()`, возвращает `-1`.

## Замена подстроки

```go
strings.Replace("foo bar foo", "foo", "baz", 1)  // "baz bar foo"
strings.Replace("foo bar foo", "foo", "baz", -1) // "baz bar baz"
```

Четвёртый аргумент — число замен. `-1` означает заменить все вхождения.

## Повторение строки

```go
strings.Repeat("na", 3) // "nanana"
```

Функция `Repeat` возвращает новую строку, повторяя исходную указанное число раз. Если указать 0 — вернётся пустая строка.

## Удаление пробелов в начале и конце

```go
strings.TrimSpace("  hello\n") // "hello"
```

Удаляются пробелы, табуляция, переносы строк.

## Удаление символов по краям

Когда с краёв строки нужно убрать другие символы, например восклицательные знаки, используется `strings.Trim()`.

```go
strings.Trim("!!hi!", "!") // "hi"
```

Вторым аргументом `strings.Trim()` принимает набор символов и убирает их с обоих концов строки. Символы в середине строки функция не трогает.

## Разбиение на слова

Чтобы обработать слова текста по отдельности, строку делят функцией `strings.Fields()`.

```go
strings.Fields("  go is  fun ") // []string{"go", "is", "fun"}
```

В этом примере `strings.Fields()` делит строку по пробелам и возвращает срез слов. Лишние пробелы в начале, в конце и между словами отбрасываются. Срез это последовательность значений одного типа, и подробно срезы разбираются дальше по курсу.

## Срезы строк (slicing)

В Go можно получать части строки, указывая диапазон индексов в квадратных скобках. Индексы задаются по позиции байтов, начиная с 0.

```go
text := "golang"

// символы с позиции 0 до 2, не включая 2
fmt.Println(text[0:2]) // => "go"

// от начала до позиции 4
fmt.Println(text[:4])  // => "gola"

// от позиции 3 до конца строки
fmt.Println(text[3:])  // => "ang"

// вся строка
fmt.Println(text[:])   // => "golang"
```

Отрицательных индексов, как в Python, в Go нет, и на запись `text[-3:]` компилятор отвечает `invalid argument: index -3 (constant of type int) must not be negative`. Последние символы строки отсчитываются от её длины, которую возвращает `len()`.

```go
// последние три символа
fmt.Println(text[len(text)-3:]) // => ang
```
