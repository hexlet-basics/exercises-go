Реализуйте функцию `GetHiddenCard(cardNumber string, starsCount int) string`, которая принимает на вход номер кредитной карты в виде строки и возвращает её скрытую версию.

Скрытая версия состоит из N звёздочек и последних четырёх символов исходной строки. Количество звёздочек задаётся вторым параметром.

## Примеры

```go
GetHiddenCard("1234567812345678", 2) // "**5678"
GetHiddenCard("1234567812345678", 3) // "***5678"
GetHiddenCard("1234567812345678", 4) // "****5678"
GetHiddenCard("2034399002121100", 1) // "*1100"
GetHiddenCard("378282246310005", 2)  // "**0005"
```

## Подсказки

- Отрицательных индексов, как в Python, у строк в Go нет. Позиция, с которой начинаются последние символы, считается от длины строки `len()`.
