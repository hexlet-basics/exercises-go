Напиши функцию `FilterString(text string, exclude rune) string`, которая получает строку и символ. Символ передаётся руной, то есть литералом в одинарных кавычках, например `'i'`. Функция должна вернуть новую строку без всех букв, совпадающих с этим символом — неважно, большие они или маленькие (например, `A` и `a` считаются одинаковыми). Остальные символы строки остаются как были, вместе с их регистром.

```go
FilterString("If I look forward I win", 'i') // "f  look forward  wn"
FilterString("If I look forward I win", 'O') // "If I lk frward I win"
```

Для приведения символов к нижнему регистру используйте функцию `unicode.ToLower()`:

```go
import "unicode"

r := 'A'
unicode.ToLower(r) // 'a'
```

К нижнему регистру для сравнения приводятся оба символа, и символ из строки, и переданный `exclude`.
