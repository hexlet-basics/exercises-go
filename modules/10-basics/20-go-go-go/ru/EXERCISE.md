Написать интересный код самостоятельно на текущем уровне будет затруднительно, поэтому скопируйте код ниже и запустите его.

```go
wg := sync.WaitGroup{}

for i := range 3 {
	wg.Add(1)
	go func() {
		fmt.Println("Go! " + strconv.Itoa(i))
		wg.Done()
	}()
}

wg.Wait()
```

Что делает этот код:

- `go func() { ... }()` запускает функцию в отдельной горутине. Цикл повторяется три раза, поэтому три вызова `fmt.Println()` выполняются конкурентно, а не один за другим.
- Порядок вывода не определён. Строки `Go! 0`, `Go! 1` и `Go! 2` печатаются в произвольном порядке, и от запуска к запуску он может меняться.
- `sync.WaitGroup` это счётчик незавершённых горутин: вызов `wg.Add(1)` увеличивает его перед запуском горутины, `wg.Done()` уменьшает по её завершении, а `wg.Wait()` не выпускает `main()` дальше, пока счётчик не станет нулевым. Без него программа завершилась бы раньше горутин, и вывода могло не быть вовсе.

Запустите решение несколько раз и посмотрите, меняется ли порядок строк.
